# Contributing / 参与贡献

Thanks for improving Rolling Fitness Coach! 欢迎贡献建议、文档、自动化测试和新的匿名模拟场景。

1. Open an issue to describe a bug, expected behavior, and reproduction steps. **Do not upload body photos, medical information, live nutrition/fitness logs, personal chats, API tokens, or screenshots containing private information.** Use fictional examples.
2. Keep training/food examples clearly labeled as synthetic. Distinguish planned from completed sets and consumed from merely ordered items.
3. Add or update tests for any changes to the logging CLI. Run `python -m unittest discover -s tests -v`.
4. Safety-related changes should preserve uncertainty, referral for concerning symptoms, and privacy guarantees.
5. Submit concise pull requests explaining changed user-facing behavior and any known limitations.

This is a coaching workflow, not a medical device. Contributions must not overpromise diagnosis, precise body-fat estimation, or automatic continuous monitoring.
