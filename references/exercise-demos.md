# 动作演示与媒体引用规范

## 教学目的

用户在健身房需要快速看到动作、训练部位、正确发力、常见错误与疼痛停止信号。手机屏幕优先排版：上方训练清单，动作按顺序显示，每个动作最多1张清晰示意、2–4句动作关键点、一个短文字链接。

## 媒体选择

1. 可用可靠来源时：找具体动作名称与器械一致的教学视频（如 StrengthLog、ExRx、Muscle & Strength 的动作教学页或信誉良好的机构视频）并实际核实 URL 与动作相符；链接显示“动作演示”，不要堆长URL。
2. 图片能力存在时：使用可靠动作示意或用户提供的器械图来帮助识别；不是凭搜索图证明用户做得正确；不可通过视觉推断隐形关节受力。
3. 无视频/图片来源时：输出简短文字分解 + 可供用户自行检索的准确中英动作名，声明未验证链接，绝不能臆造某视频网站 BV 号或视频地址。
4. 视频与图片版权按工具及授权遵循，不把受版权保护的整段视频或下载图片打包进 Skill。此项目不内置真实动作照片。

## 动作卡标准

```
动作：绳索侧平举 | 3组×12–20次 | 休息75秒 | RIR 1–2
目标：三角肌中束
起点：滑轮低位，手臂稍前于身体侧方
发力：上臂往外抬，不甩手腕；缓慢离心约2秒
常见错误：耸肩、身体大幅侧倾、借力摆动
不适：出现肩前侧锐痛则停止并换动作
演示： [经验证的具体网址] 或 [暂无可验证演示]
```

## 常见动作 — 主要排错提示

| 动作 | 正确关注点 | 常见不适/替代 |
|---|---|---|
| 上斜卧推 | 凳子约15–30°为常见起点，肩胛稳定，下降受控 | 肩前疼/肘不适→减幅度/减重或换胸推机 |
| 器械胸推 | 把手大致胸中线，肩部稳定、腕中立 | 手臂过度发力→检查椅高、握距、肘角和重量，不凭酸胀判无效 |
| 器械推肩 | 把手由肩附近沿舒适路径上推，避免腰拱 | 推肩更偏前束/三头，不能等同上胸卧推 |
| 绳索/哑铃侧平举 | 手肘略屈、上臂带动、慢放 | 耸肩摆动→大概率过重，降负重 |
| 高位下拉 | 手肘向下靠近身体两侧，躯干稳定 | 大幅后仰→减重；换辅助引体 |
| 胸托划船 | 胸稳靠垫、控制回放 | 借腰甩动→减重；换坐姿划船 |
| 腿举 | 脚掌踩稳、膝跟脚尖、臀不离垫 | 骨盆卷曲→减深度；换哈克/高脚杯蹲 |
| 罗马尼亚硬拉 | 推臀、脊柱稳定、后侧拉伸 | 腰部无法稳定→减重学髋铰链或用腿弯举 |
| 反向蝴蝶机 | 胸贴垫、后束发力、稳定躯干 | 耸肩或肩痛→减重/调整手柄 |
| 腿弯举 | 调座椅轴心、骨盆稳定、缓慢回放 | 抬臀→调重量和座椅 |

训练现场面对器械照片，若不能识别是肩推还是推胸，先说明不确定，再问把手从胸前向前、从肩旁向上还是从腰侧向下；根据答案再替换动作。
