# 初始建档与视觉评估

## 最小充分建档

优先复用已知信息，缺少则逐步询问：目标（增肌/力量/薄肌/维持）、训练频率与每次时长、训练经验、偏好的动作器械、最近已练/恢复情况、受伤/疼痛/医疗限制。营养需知道大致身高体重/体重趋势、饮食偏好、过敏或限制。

可选：年龄范围、性别（只有在估算相关并由用户自愿提供时）、日常活动、腰围等。不要强迫用户分享裸露照片；非必要不索取精确定位或身份。

## 照片阅读决策

| 观察对象 | 可谨慎描述 | 不可下结论 |
|---|---|---|
| 正面、背面、侧面 | 可见肌肉轮廓、姿势趋势、衣服和光照影响 | 精确体脂率/骨宽/疾病/肌肉量公斤数 |
| 放松与屈肌姿态 | 不同展示状态的视觉差异 | 单张“已经进步了X%” |
| 腰腹 | 可见腰线、脂肪分布的粗略视觉情况 | 内脏脂肪/代谢健康 |
| 家用生物电阻抗 | 记录测量值与时间 | 当成误差很小的真实体脂/肌肉量 |

照片评估时说清楚哪些部位看不见（腿和背部尤其常见）。不拿示意照片当用户本人，也不要对外貌贬损。肩窄视觉感可以由三角肌中束、背阔发育与镜头角度共同影响；成年骨骼宽度不可通过训练自由改变。

## 体重趋势

推荐每周至少2–4次在尽量相近条件下测量（如晨起如厕后、进食前），看7日平均。训练后/大量喝水/出汗后变化不能用于判断肌肉变化。健康增肌可能以缓慢增重作参考，但速度应由体重趋势、腰围和恢复调整，绝不强制。

## 将目标映射为训练配置（仅示例）

- 薄肌、肩宽：三角肌中束与后束、背阔、上胸优先，仍保留腿、核心。
- 时间少：优先复合动作+优先肌群孤立；跳过低收益辅助动作。
- 更有训练经验：不能直接套“新手最小组数”；先查看当前周训练量和停滞情况，再决定增减。
